ERPEditor 範例

在套件根目錄執行 npm run serve，再開啟 http://localhost:8090/examples/。

  1. 基本使用：一行建立編輯器、取得 HTML
  2. 綁定 textarea 與表單送出：不用寫同步程式
  3. API 與事件：setHTML、change 事件、唯讀、即時預覽、字數
  4. 自訂工具列、語系、顏色與主題
  5. 圖片上傳與自訂對話框：imageUpload、promptLink
  6. 在 Bootstrap 5 modal 中使用：重複開啟、深色模式
  7. 搭配 jQuery 與 AJAX：傳統後台寫法
  8. php/form.php：PHP 後端過濾（需 PHP，執行 php -S localhost:8091 -t examples/php）
  9. 測試頁
